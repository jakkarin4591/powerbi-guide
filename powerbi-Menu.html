Power BI Desktop Guide

คู่มือเมนู Power BI

รวมคำอธิบายกลุ่มคำสั่งทั้งหมดใน Power BI Desktop พร้อมตัวอย่างการใช้งาน

🏠

Home (หน้าแรก)

รวมคำสั่งพื้นฐานในการใช้งาน Power BI Desktop

แท็บ Home เป็นจุดเริ่มต้นหลักของ Power BI Desktop ประกอบด้วยกลุ่มคำสั่งสำหรับนำเข้าข้อมูล สร้าง Visual เผยแพร่รายงาน และใช้งาน Copilot AI

📸 ตัวอย่าง Ribbon แท็บ Home

✂️

Clipboard

คำสั่งการคัดลอก ตัด และวางข้อมูล วิชวลต่างๆ บนรายงาน เช่น Cut / Copy / Paste / Format Painter

🗄️

Data

คำสั่งนำเข้าข้อมูลจากแหล่งข้อมูลภายนอก ได้แก่ Get data, Excel workbook, OneLake catalog, SQL Server, Enter data, Dataverse และ Recent sources

🔄

Queries

เปิดโปรแกรม Power Query (Transform data / Refresh) สำหรับแก้ไข เชื่อมต่อ และแปลงข้อมูลก่อนโหลดเข้ารายงาน

📊

Insert

สำหรับแทรกวิชวลใหม่ (New visual), กล่องข้อความ (Text box) และวิชวลเพิ่มเติม (More visuals) ลงในรายงาน

🧮

Calculations

คำสั่งช่วยสำหรับการเขียนนิพจน์ DAX ได้แก่ New visual calculation, New measure และ Quick measure เพื่อคำนวณข้อมูลขั้นสูง

🔒

Sensitivity

คำสั่งในการป้องกันข้อมูลที่เป็นความลับถูกเผยแพร่ (ต้องมีใบอนุญาต Azure Information Protection ก่อน)

🌐

Share

คำสั่งในการเผยแพร่รายงาน (Publish) บน Power BI Service เพื่อแชร์กับผู้อื่นในองค์กรแบบออนไลน์

🤖

Copilot

ฟีเจอร์ใหม่! ใช้ AI Copilot ช่วยเตรียมข้อมูลและสร้างรายงานอัตโนมัติด้วยคำสั่ง "Prep data for AI" ผ่าน Microsoft Copilot

➕

Insert (แทรก)

รวมคำสั่งในการสร้างหน้าเอกสาร การสร้างแผนภูมิ และการแทรกปุ่ม กรอกข้อความ และภาพต่างๆ

แท็บ Insert ใช้เพิ่ม Visual, หน้ารายงาน, องค์ประกอบ AI และการเชื่อมต่อ Power Platform ลงในรายงาน

📸 ตัวอย่าง Ribbon แท็บ Insert

📄

Pages

ใช้ในการสร้างหน้ารายงานใหม่ โดยเลือกเป็นการสร้างหน้าเปล่าหรือทำซ้ำหน้ารายงานเดิมได้

📈

Visuals

คำสั่งในการสร้างวิชวลใหม่ลงในรายงาน หรือเลือกนำเข้าวิชวลจากเครื่องคอมพิวเตอร์ หรือจาก AppSource

🤖

AI Visuals

คำสั่งในการเรียกใช้วิชวล AI ซึ่งมี 4 รูปแบบ ได้แก่ Q&A, Key Influencers, Decomposition Tree และ Smart Narrative

⚡

Power Platform

ใช้ในการฝังแอป Power ADDS ในรายงานของเรา โดยจะทำงานแบบเรียลไทม์เมื่อมีการเปลี่ยนแปลงข้อมูล

🔲

Elements

คำสั่งใช้ในการแทรกกล่องข้อความ ปุ่ม รูปร่าง (Shapes) หรือรูปภาพ (Image) ในรายงานของเรา

✨

Sparklines

คำสั่งใช้ในการแทรกเส้นประกายไฟที่เป็นแผนภูมิขนาดเล็กในวิชวลที่มีรูปแบบเป็น Table และ Matrix เพื่อแสดงแนวโน้มข้อมูล

🔧

Modeling (การวางรูปแบบ)

รวมคำสั่งในการสร้างตาราง กำหนดพารามิเตอร์ต่างๆ และการแก้ไขรูปแบบภาษา

แท็บ Modeling ใช้จัดการความสัมพันธ์ระหว่างตาราง เขียนนิพจน์ DAX สร้างพารามิเตอร์ What if และกำหนดความปลอดภัยของข้อมูล

📸 ตัวอย่าง Ribbon แท็บ Modeling

🔗

Relationships

คำสั่งในการเพิ่ม แก้ไข หรือลบความสัมพันธ์ระหว่างตาราง

🧮

Calculations

คำสั่งช่วยสำหรับการเขียนนิพจน์ DAX เช่น New measure, Quick measure, New column, New table

🔁

Page refresh

คำสั่งในการตรวจจับการเปลี่ยนแปลงของข้อมูลและรีเฟรชหน้ารายงานอัตโนมัติ

🎛️

What if (Parameters)

สำหรับสร้างพารามิเตอร์ What if เพื่อดูวิธีที่ข้อมูลทำงานภายใต้เงื่อนไขต่างกัน สามารถเพิ่มพารามิเตอร์ลงในรายงาน อ้างอิงในนิพจน์ DAX อื่นๆ ได้

🔒

Security

คำสั่งเกี่ยวกับการรักษาความปลอดภัยในการสร้าง เปลี่ยนแปลง หรือลบบทบาท โดยการเขียนคำสั่ง DAX เพื่อสร้างตัวกรองข้อมูลการมองเห็น

💬

Q&A

การตั้งค่าระบบถามตอบ (วิชวล Q&A) เพื่อใช้ในการตรวจสอบ และจัดการข้อความที่ค้นหาหรือเพิ่มเข้ามาได้

👁️

View (ดู)

รวมคำสั่งในการปรับแต่งแผนภูมิ ดูการออกแบบการจัดวางให้เหมาะสมกับหน้าจอและโทรศัพท์มือถือ

แท็บ View ใช้ปรับมุมมองรายงาน ตั้งค่า Theme จัดการ Page Options และแสดง/ซ่อนบานหน้าต่างต่างๆ

📸 ตัวอย่าง Ribbon แท็บ View

🎨

Themes

ใช้ในการกำหนดธีมให้กับวิชวลที่เราสร้างขึ้น และสามารถสร้างธีมใหม่ให้อยู่ในรูปแบบองค์กรของเราได้อีกด้วย

🔍

Scale to fit

ใช้ในการปรับมุมมองหน้ารายงาน สามารถปรับขนาดหน้าให้พอดีกับหน้าจอ ปรับขนาดให้พอดีในแนวกว้าง และตั้งค่าขนาดตามจริง

📱

Mobile

ใช้ในการออกแบบหน้ารายงานสำหรับอุปกรณ์เคลื่อนที่ เพื่อให้รายงานแสดงผลได้ดีบนโทรศัพท์มือถือ

📄

Page Options

ตัวเลือกในการจัดการหน้ารายงาน (Page) โดยติ๊กเลือกให้แสดงเส้นตารางเพื่อช่วยจัดแนววัตถุ ติ๊กเลือกจัดแนววัตถุในรายงาน อัตโนมัติ และล็อกวัตถุทั้งหมดไว้

🪟

Show panes

คำสั่งใช้ในการแสดง/ซ่อนบานหน้าต่างเพิ่มเติม เพื่อเพิ่มประสิทธิภาพในการใช้งาน เช่น Filters, Bookmarks, Selection, Performance analyzer และ Sync slicers

⚡

Optimize (ปรับประสิทธิภาพ)

รวมคำสั่งสำหรับปรับปรุงประสิทธิภาพการแสดงผลของรายงาน Power BI

แท็บ Optimize ใช้จัดการการแสดงผล ปรับค่าประสิทธิภาพ และตรวจสอบการทำงานของรายงาน

📸 ตัวอย่าง Ribbon แท็บ Optimize

🔍

Queries

Pause visuals — คำสั่งที่ใช้เพื่อหยุดการแสดงผลข้อมูลบนรายงาน ช่วยลดภาระการประมวลผลขณะแก้ไขหรือปรับปรุงข้อมูล

Refresh visuals — คำสั่งที่ใช้เพื่อรีเฟรชการแสดงผลของข้อมูลบนรายงานให้ทันสมัยอยู่เสมอ

📋

Report

Optimization Presets — คำสั่งที่ใช้ในการเลือกการตั้งค่าการปรับแต่งประสิทธิภาพของรายงานในรูปแบบที่เตรียมไว้ล่วงหน้า

🔬

Review

Performance analyzer — คำสั่งสำหรับการวิเคราะห์ประสิทธิภาพของรายงาน เพื่อตรวจสอบและปรับปรุงประสิทธิภาพการแสดงผล

🎛️

Apply

Apply all slicers button — คำสั่งสำหรับการตั้งค่าปุ่มที่ใช้ Slicers ทั่วทั้งรายงาน ช่วยให้ปรับใช้งานปุ่ม Slicers ได้ง่ายขึ้น

🖥️

Overview (ภาพรวม)

ภาพรวมของเครื่องมือ Power BI Desktop และส่วนประกอบสำคัญต่างๆ

ภาพรวมหน้าจอหลักของ Power BI Desktop ประกอบด้วยส่วนสำคัญที่ต้องรู้จักก่อนเริ่มใช้งาน

📸 ภาพรวมของเครื่องมือ Power BI Desktop

📑

แถบมุมมอง

แถบด้านซ้ายสุด ใช้สลับระหว่างมุมมองต่างๆ ได้แก่ มุมมอง Report (รายงาน), Table (ตาราง) และ Model (โมเดลข้อมูล)

🗂️

แถบเมนูหลัก (Ribbon)

แถบเมนูด้านบน ประกอบด้วยแท็บ Home, Insert, Modeling, View, Optimize และ Help รวมคำสั่งทั้งหมดที่ใช้งานใน Power BI

📄

พื้นที่รายงาน (Canvas)

พื้นที่ตรงกลางหน้าจอ ใช้สำหรับวางและจัดเรียง Visual ต่างๆ เพื่อสร้างรายงานและแดชบอร์ด

📑

แถบหน้ารายงาน

แถบด้านล่างสุด ใช้จัดการหน้ารายงาน (Pages) สามารถเพิ่ม ลบ และเปลี่ยนชื่อหน้ารายงานได้ที่นี่

🔽

หน้าต่างตัวกรอง (Filters)

บานหน้าต่างด้านขวา ใช้กำหนดตัวกรองข้อมูลทั้งในระดับ Visual, หน้ารายงาน และรายงานทั้งหมด

📊

หน้าต่างวิชวล (Visualizations)

บานหน้าต่างด้านขวา ใช้เลือกประเภท Visual และกำหนดค่าการแสดงผล เช่น Fields, Format และ Analytics

🗃️

หน้าต่างเขตข้อมูล (Data)

บานหน้าต่างด้านขวาสุด แสดงรายการตารางและฟิลด์ข้อมูลทั้งหมดที่โหลดเข้ามา พร้อมใช้ลากวางเพื่อสร้าง Visual
